# FingerMath Pro

A single-page web app that teaches finger-based mental arithmetic. One
self-contained `index.html`: no build step, no dependencies, no network calls.

## Run

```
xdg-open index.html
```

## Notes

- Everything, including styles and script, lives in `index.html`.
- Published under the name "FingerMath Pro by FingTech Labs".
- The repository was called `verbose-meme`, GitHub's generated name, until it was
  renamed.
